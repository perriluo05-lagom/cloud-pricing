五大件计价单位

GPU 整机买单卡比价、CPU 按 vCPU 买、存储和网络各有多种维度不可混用

关键区分：GPU 是"整机买、单卡比价"；CPU 是"按 vCPU 买、单 vCPU 就是最小可比单位"。两者计价逻辑不同，不能混用。GPU 对账不做除法（直接对整机月价），CPU 对账做除法（÷ vCPU）。
资源类型计价单位说明
GPU 整机 USD/月
另附单 Slice 价格 = 整机价 ÷ 卡数		 整机封装出售，报价给整机价但比价换算到单卡
CPU USD/vCPU/月 按单核报价。阿里云 Default Price = 官网包月目录价 ÷ vCPU
内存 GB 通常与 CPU 绑定按比例卖（1:2 / 1:4 / 1:8），很少单独计价
存储 — 块存储 USD/GB/月 按分配容量计费。阿里云 PL0/PL1/PL2 对应 AWS gp3/gp3 高配/io2。AWS gp3 基线 3000 IOPS 免费，超出另收；io2 按 IOPS 阶梯收费
存储 — 对象存储（容量） USD/GB/月 按存储容量月费。分标准存储/冷存档存储；标准存储再分同城冗余（多 AZ）/本地冗余（单 AZ）。AWS 标准存储按用量阶梯降价
存储 — 对象存储（流量） USD/Gbps/月 或 USD/GB/月 带宽承诺 = 预留速率固定月费（写 > 读）；按量 = 实际传输 GB 计费（回源）。GB 与 Gbps 不可换算：1 Gbps 满速跑一月 ≈ 324 TB
网络 — 跨 Region USD/GB 或 USD/Mbps/月 AWS 按流量、阿里云按带宽包月。同 Region 内通常免费
网络 — 跨云专线 USD/GB + USD/端口/月 跨云物理专线，流量费 + 端口费双维度。100Gbps 端口月费数千美金
网络 — 公网 USD/GB 或 USD/Mbps/天 AWS 按流量阶梯（10/50/150TB+）；阿里云按带宽包月/包天，分国内/国际 BGP
网络 — 负载均衡 USD/LCU/小时 + USD/小时 LCU = 负载均衡容量单位（新连接/活跃连接/处理字节/规则评估取最大）；实例费按版本固定。ALB = 七层，NLB = 四层
网络 — 安全 USD/Mbps/月 或 USD/月 DDoS 保底套餐 vs 精细计费差 50-100 倍；云防火墙分包年包月版 vs 按量 2.0 版，口径不同
CDN GB 流量 $/GB + 请求数

网络分类详解

网络的每个子类是什么、怎么收费、为什么需要——按计费维度逐一拆解

🔄

同云跨 Region 数据流出

网络
同一个云厂商内部，不同地域之间的数据传输费。如新加坡→北美、中国大陆→新加坡
计费单位USD/GB（AWS 按流量）
USD/Mbps/月（阿里云按预留带宽）
计费逻辑用多少传多少付多少（AWS），或包月固定带宽费（阿里云）。跨 Region 传数据是云厂收入项，价格远高于同 Region 内传输（同 Region 内通常免费）
大流量传输考虑走专线或中转优化；阿里云按带宽包月时利用率低会亏
🔌

跨云专线数据流出

网络
通过物理专线（DX / 专线 / Cloud Exchange）从一个云把数据传到另一个云
计费单位USD/GB（流量）+ USD/端口/月（端口）
计费逻辑两笔费用叠加：流量费按实际 GB 计 + 端口费固定收（与流量无关）。100Gbps 端口月费可达数千美金
端口费是固定成本，流量少时占比高。谈判时可谈端口 + 流量包月套餐
🌐

公网（共享带宽-BGP）

网络
业务面向互联网的出口带宽，用户通过公网访问云上资源
计费单位USD/GB（AWS 按流量阶梯）
USD/Mbps/天（阿里云按带宽）
计费逻辑AWS 按流量阶梯（10/50/150TB+ 逐级降价）；阿里云按带宽包月/包天。一个按量一个按速
AWS 无共享带宽包概念，每条 EIP 独立计费；阿里云可多 EIP 共享带宽池。BGP 分国内/国际，国际便宜约一半
⚖️

负载均衡 ALB/NLB

网络
将流量分发到多台后端服务器。ALB 处理 HTTP/HTTPS（七层），NLB 处理 TCP/UDP（四层）
计费单位USD/LCU/小时（容量）+ USD/小时（实例）
计费逻辑双维度计费：LCU = 负载均衡容量单位，按处理量动态折算（新连接/活跃连接/处理字节/规则评估取最大）；实例费按版本固定。两笔独立叠加
LCU 和实例费容易填反（ALB LCU=0.007-0.021，实例费按版本），对账时先确认计费维度
🛡️

DDoS 防护

网络
防御分布式拒绝服务攻击。基础版免费/低配，高级版付费
计费单位USD/Mbps/月（阿里云按防护带宽）
USD/月（AWS 固定套餐）
计费逻辑阿里云保底防护带宽按套餐（折算 USD/Mbps/月 极低 0.05-0.12），业务带宽精细计费（个位数 USD/Mbps/月），两者差 50-100 倍
保底防护带宽 vs 业务带宽是两个维度，单价差 50-100 倍。海外版 DDoS 分 3 个子文档（保险/无限/加速），需确认接入模式
🔥

云防火墙

网络
云原生的网络防火墙服务，对 VPC 内流量做访问控制和安全过滤
计费单位USD/小时 + USD/GB（AWS）
USD/Mbps/月 + USD/个（阿里云）
计费逻辑AWS 按端点小时费 + 数据处理费双维度；阿里云包年包月版按实例个数 + 扩容带宽
表内填的是包年包月版，官网链接可能是按量 2.0 版（按 GB 流量 + 小时实例费），口径完全不同。按量 2.0 还含 IPS / 日志分析等额外计费项
为什么网络类比实例难对账： 实例是一维计价（一台机器一个价），网络是多维计价——一个产品的费用由多个计费维度叠加，各维度单位互不可换算。
计费维度含义典型单位代表产品为什么容易踩坑对账要点
按量 按实际数据量收费用多少付多少USD/GBAWS 出口流量、跨 Region 流出用量波动大时成本不可预测，预算难做用账单 GB × 单价逐月复算
按速率 按预留带宽收固定月费用没用满都付USD/Mbps/月阿里云共享带宽、跨 Region 预留带宽利用率低就是白花钱；与按量价不可直接比较先算带宽利用率，再与按量方案比总成本
固定+用量 固定费与用量费叠加固定月费 + 按量费两笔独立USD/端口/月 + USD/GB跨云专线（DX / 专线 / Cloud Exchange）流量少时固定费占比极高，平均单价失真拆成端口费、流量费两笔分别对账
复合单位 厂商自造容量单位多项指标折算后取最大值USD/LCU/小时负载均衡 ALB/NLB单位看不懂就没法比价；LCU 与实例费容易填反先查 LCU 定义，LCU 费与实例费分开核
阶梯 用量分段逐级降价每段单价不同USD/GB（分段）AWS 公网出口（10/50/150TB+ 三段）平均单价随用量变化，无法用单一单价对账按账单分段逐段核对，不做平均
版本口径 同产品多版本计费不同版本不同模式完全不同包月 USD/Mbps/月 vs 按量 USD/GB云防火墙（包年包月版 vs 按量付费 2.0）官网文档常指向另一版本，数字对不上不一定是填错先确认产品版本，再找对应版本的价目
对账三步法网络类对账的标准动作：第一步认计费维度，第二步对单位，第三步才比价格——维度不同的两列数字没有可比性，直接比价必错

存储分类详解

存储的每个子类是什么、怎么收费、为什么需要——按计费维度逐一拆解

💾

块存储 — 云盘 PL0

存储
最低性能档云硬盘，适合系统盘 / 轻量应用。对应 AWS gp3
计费单位USD/GB/月
计费逻辑按分配容量计费。AWS gp3 基线 3000 IOPS 免费，超出的 IOPS 和吞吐量另收费（$0.005/IOPS/月、$0.04/MB/s/月）
AWS 块存储不只按 GB 收，IOPS 超基线和吞吐超基线都要加钱，高 IO 场景成本可能翻倍
💾

块存储 — 云盘 PL1

存储
中档云硬盘，适合大多数业务应用。对应 AWS gp3 高 IOPS 配置
计费单位USD/GB/月
计费逻辑按分配容量计费，单价高于 PL0。PL1 是阿里云最常用的通用云盘档位
💾

块存储 — 云盘 PL2

存储
高性能云硬盘，适合数据库等高 IO 场景。对应 AWS io2
计费单位USD/GB/月
计费逻辑按分配容量计费，单价最高。AWS io2 的 IOPS 无免费额度，阶梯递减（前 32K = $0.065/IOPS/月，32K-64K = $0.046，64K+ = $0.032）
io2 按 IOPS 阶梯收费，IOPS 越高单价越低但总量越大成本越高，需精确预估 IOPS 需求
📦

对象存储 — 标准存储

存储
最常用的对象存储，存频繁访问的数据（图片/视频/日志）。分同城冗余（多 AZ）和本地冗余（单 AZ）
计费单位USD/GB/月
计费逻辑按存储容量月费。同城冗余贵于本地冗余。AWS 还按用量阶梯降价（前 50TB / 51-500TB / 500TB+）
同城冗余 = 数据跨多 AZ 副本，更安全更贵；本地冗余 = 单 AZ，便宜但 AZ 挂了数据不可用
📦

对象存储 — 冷存档存储

存储
极少访问的冷数据存储（备份 / 归档 / 合规留存），价格极低但取回慢
计费单位USD/GB/月
计费逻辑单价仅标准存储的 1/10 到 1/100。AWS Glacier Deep Archive $0.00099/GB/月，阿里云 $0.002/GB/月
取回需要分钟到小时级时间，且可能另收恢复费。适合合规留存数据，不适合业务数据
📤

对象存储 — 读写/回源流量费

存储
对象存储的数据读写和外部访问产生的流量费用
计费单位USD/Gbps/月（写/读，带宽承诺）
USD/GB/月（回源，按量）
计费逻辑带宽承诺 = 预留速率固定月费（用没用满都付）；按量 = 实际传输 GB 计费。写贵于读，回源最便宜
USD/GB（数据量）vs USD/Gbps/月（带宽速率）是完全不同的维度，不可换算。1 Gbps 满速跑一月 ≈ 324 TB。大流量场景带宽承诺碾压按量
为什么存储类比实例难对账： 存储的费用由容量、性能、流量、请求等多个独立维度叠加，且各维度单位互不可换算。
计费维度含义典型单位代表产品为什么容易踩坑对账要点
按容量 按分配容量收月费与实际写入量无关USD/GB/月云盘（PL0-PL2）、对象存储分配了不用也照付，超配就是浪费对账核分配量而非实际使用量
性能另收 IOPS/吞吐超基线加钱超基线部分独立计价USD/IOPS/月、USD/MB/s/月AWS gp3（3000 IOPS 基线）、io2（无免费额）以为只付容量费，高 IO 场景成本可能翻倍IOPS 费、吞吐费与容量费分开核对
冷热分层 越冷存越便宜取回越贵存储单价与取回费反向存 USD/GB/月 + 取回费另计标准存储 vs 冷存档（Glacier Deep Archive）热数据误放冷层，取回费可能反超省下的钱按取回频率定层级，不只看存储单价
多单位叠加 容量/带宽/请求独立计费三者互不换算USD/GB + USD/Gbps/月 + USD/万次对象存储读写/回源流量费单位混填则整列报废；GB 与 Gbps 不可换算换算锚点：1 Gbps 满速跑一月 ≈ 324 TB，先统一口径再比
冗余选项 同城冗余贵本地便宜多 AZ 副本 vs 单 AZUSD/GB/月（两档单价）对象存储标准存储买错档位：多花钱或容灾不达标先确认业务容灾要求，再定冗余档
对账三步法存储类对账的标准动作：第一步认计费维度，第二步对单位，第三步才比价格——维度不同的两列数字没有可比性，直接比价必错
